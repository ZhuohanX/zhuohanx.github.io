# Zhuohan Xie

Personal academic homepage for https://zhuohanx.github.io/.

## News maintenance

Check News whenever a new publication, acceptance, invited talk, or service milestone is verified in the Scholar and academic-management chat. Use the event or publication month, place recent items first, and keep the visible list to about eight entries; preserve older announcements in the existing archive.

Link papers to their final publication records when available, label preprints explicitly, and distinguish an event organizer from its venue. Update the footer date only when the page content actually changes. This workflow is tied to verified progress; it does not imply an unattended publishing job.
